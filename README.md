# yurifreitas.github.io

Site pessoal de Yuri Freitas — engenharia de software e IA aplicada.

**https://yurifreitas.github.io**

## Stack

React 19 · Vite · TypeScript · CSS Modules · Atomic Design. Conteúdo em PT, EN e ES.

## Rodar

```bash
npm install
npm run dev
```

## Estrutura

- `src/content/` — todo o conteúdo e as traduções
- `src/components/` — atoms, molecules, organisms e templates
- `src/design/` — tokens e estilos globais

O deploy para o GitHub Pages roda a cada push na `master` (`.github/workflows/deploy.yml`).
